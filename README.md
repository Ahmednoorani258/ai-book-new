# Website

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Installation 

```bash
yarn
```

## Local Development

```bash
yarn start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
yarn build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Deployment

Using SSH:

```bash
USE_SSH=true yarn deploy
```

Not using SSH:

```bash
GIT_USER=<Your GitHub username> yarn deploy
```

If you are using GitHub pages for hosting, this command is a convenient way to build the website and push to the `gh-pages` branch.

## Backend Setup with Neon Serverless Postgres

The backend for this project uses Node.js with Express.js and integrates with **Better Auth** for authentication, utilizing a **PostgreSQL** database. To use a **Neon Serverless Postgres** database, follow these steps:

1.  **Provision a Neon Database**: Create a new project and database instance on the [Neon website](https://neon.tech/). Obtain your database connection string.
2.  **Environment Variables**:
    *   Navigate to the `backend/` directory.
    *   Create a `.env` file (if it doesn't exist already) by copying `backend/.env.example`.
    *   Set the `DATABASE_URL` variable in `backend/.env` to your Neon database connection string.
    *   Set `BETTER_AUTH_SECRET` to a strong, random key (e.g., generated by `openssl rand -base64 32`).
3.  **Install Backend Dependencies**:
    ```bash
    cd backend/
    npm install
    ```
4.  **Run Migrations**: Apply the necessary database schema for Better Auth.
    ```bash
    npm run db:migrate-auth
    ```
5.  **Start Backend Server**:
    ```bash
    npm run build
    npm start
    ```
    The server should start on port `3000` (or as configured).
